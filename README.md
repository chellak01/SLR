# SLR
Being able to recognize sign language is an interesting computer vision problem while simultaneously being extremely useful for deaf people to interact with people who don't know how to understand ISL(Indian Sign Language).Sign language includes gestures made with the hands and use primarily by people who are deaf. 

![image](https://user-images.githubusercontent.com/94176113/191557939-bf54ade8-b48b-449b-a9ce-f5f836423665.png)
The process of converting the signs and gestures shown by the user into text is called Sign Language Recognition. It bridges the communicationgap between people who cannot speak and the general public. Sign Language is the primary communication in deaf community.
Speech impaired people use hand sign and gestures to communicate. Normal people face difficulty in understanding there language. Hence there is a need of a system which recognizes the different signs, gestures and conveys the information to the normal people.

![image](https://user-images.githubusercontent.com/94176113/191561346-707bb0a1-9646-47ba-b3f1-2c8029ea797b.png) ![image](https://user-images.githubusercontent.com/94176113/191562143-d2bd2436-9021-4e7c-aabd-77aee5badb5b.png)
Image processing algorithms along with neural network is used to map the gesture to appropriate text that can be read and understood. It bridges the gap between physically challenged people and normal people.

Since people with hearing impairment or deaf people cannot talk like normal people so they have to depend on some sort of visual coomunication in most of the time. as like othr language, sign language has also got grammar and vocabulary but uses visual modality for exchanging information. 
The project aims to determine human gestures by creating an coding of these gestures into machine  language where we mainly focus on Image processing and Template matching for better output generation.

## Problem Statement
Speech impaired people use hand signs and gestures to communicate. There is
a need of a system which recognizes the different signs, gestures and conveys
information. Here we study and develop system by using different algorithm
to take the image of the human hand for recognition of the gestures where the
signs represent alphabets and numbers recognized using planned technique It
bridges the gap between physically challenged people to communicate in a
normal and easy way.
